# Mushroom Classification and Detection using Deep Learning

## Overview

This project focuses on developing an AI-based system to classify poisonous and non-poisonous mushrooms using CNN and Transfer Learning, combined with YOLOv8 for mushroom detection.

## Methods

- YOLOv8 Object Detection
- CNN
- Transfer Learning
- TensorFlow/Keras
- Image Processing

## Model Architecture

Classification:
- ResNet50 / MobileNetV2

Detection:
- YOLOv8

## Features

- Mushroom object detection
- Mushroom classification
- Deep learning based prediction

## Technologies

- Python
- TensorFlow
- Keras
- OpenCV
- YOLOv8
- Roboflow
